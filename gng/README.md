# gng — أدوات Ghadir OS

كل ما يعمل **فوق** النواة ginux. النواة نفسها في `../ginux/` ولا تحتوي أدوات.

|---|---|---|

## قواعد مشتركة لأي برنامج يعمل على ginux
- **32-bit ساكن** (`-m32 -static`)، بلا مكتبات مشتركة (لا محمّل ديناميكي بعد).
- **مربوط عند 0x40000000 فما فوق**: `-Wl,-Ttext-segment=0x40000000` (محمّل النواة يرفض أي `PT_LOAD` خارج `[0x40000000, 0x80000000)`).
  ولبرامج يربطها `ld` داخل ginux استعمل `-Ttext-segment` وليس `-Ttext`.
- **segments منفصلة**: لا segment قابل للكتابة والتنفيذ معًا (سياسة W^X)، والإعدادات الافتراضية للربط الحديث تحقق ذلك.
- النواة تفعّل SSE وتحفظ حالته عند تبديل السياق، فالمكتبات الحديثة التي تستعمله تعمل، وكود الحقبة القديمة يعمل كذلك.

## بناء أداة من المصدر
    gng/dietlibc/build.sh     # دقائق
    gng/tcc/build.sh          # دقيقة
    gng/binutils/build.sh     # ~ساعة على معالج واحد
    gng/gcc/build.sh          # ساعات (مُجمَّع من أوامر نُفِّذت يدويًا ولم يُعَد تشغيله كاملًا)
    gng/glibc/modern-hello/build.sh
كل سكربت يضع ناتجه في `prebuilt/`. وفيه شرح للمتطلبات في أول الملف.

## ملاحظة عن مكتبة الـ C الخاصة (libgng)
مكتبة GNG الأصلية (`libgng.a`، و`crt0.o`، وبرنامج `gng-hello`) لم تكن ضمن الملفات التي اشتغلتُ عليها، فلم أنقلها هنا.
ضعها في `gng/libc/` عند دمجها.
